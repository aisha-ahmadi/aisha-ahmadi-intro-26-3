# Open API Project
This is an API integration that is linked to the portfolio page and fetches data from the CAT API to display photos and breed profiles of different cats. 

## To run the project locally:
Follow these instructions:

1. **Download the project. 
* Download the project's ZIP file and extract it to your computer. 

2. **Open the Portfolio Page. 
* Locate the main folder on your computer.
* Double-click the 'index.html' that is at the root level of the folder. This should open up the portfolio landing page in your browser. 

3. **Locate the 'Open API' subpage. 
* Use the navigation menu at the top of the portfolio landing page and click the **Open API** link. 
* This should take you to the gallery of cat images where you can toggle between **Cat Photos** and **Breed Directory**.
